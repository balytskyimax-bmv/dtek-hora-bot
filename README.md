# 💡 Telegram Bot: Графіки відключення світла ДТЕК (с. Гора)

Автономний Telegram-бот для автоматичного відстеження та надсилання графіків відключень електроенергії від **ДТЕК Київські регіональні електромережі (КРЕМ)** за адресою:
📍 **с. Гора, вул. Басейна, 20**
⚡️ **Черга (група): 5.1**

---

## 🚀 Основний функціонал

1. **Автоматичний щоденний моніторинг (кожні 10 хв):**
   * Як тільки ДТЕК публікує новий графік на завтра (зазвичай між 18:00 та 22:00) — бот миттєво надсилає його в топік.
   * Якщо графік змінюється протягом дня через команди Укренерго — бот надсилає сповіщення про оновлення 🚨.
2. **Інтерактивні команди:**
   * `/today` (або `/світло`) — розклад на сьогодні, поточний стан світла в реальному часі та час до наступного вимкнення/увімкнення.
   * `/tomorrow` (або `/завтра`) — графік на завтра (якщо вже опубліковано ДТЕК).
   * `/image` (або `/графік`) — офіційне графічне зображення-інфографіка від ДТЕК.
   * `/check` — позачергова ручна перевірка сайту ДТЕК.
   * `/status` — статус системи та час останнього оновлення на сервері ДТЕК.
   * `/set_topic` — встановити поточну тему супергрупи для сповіщень.
   * `/init_topic` — автоматично створити тему "💡 Світло / Гора".
3. **Естетичний формат повідомлень:**
   * 📊 Візуальна шкала 24 годин (`🟩 є світло`, `🟥 немає світла`, `🟧 30 хв`).
   * ⏰ Згруповані часові інтервали з тривалістю.
   * ⏳ Підсумок доби (всього годин без світла та зі світлом).
   * 🖼 Опціональне надсилання офіційної графічної інфографіки.

---

## 🛠 Налаштування в Telegram

1. Додайте бота `@svitlogorabot` у вашу сімейну групу:
   * Надайте йому права адміністратора (особливо **«Управління темами / Manage Topics»** та **«Публікація повідомлень»**).
2. Запустіть бота:
   * Бот автоматично спробує створити окремий топік **"💡 Світло / Гора"** і закріпити туди сповіщення.
   * Або ви можете створити топік власноруч і відправити в ньому команду `/set_topic`.

## 💻 Запуск на сервері через Docker (рекомендовано)

Проєкт підготовлено до автономної роботи в Docker-контейнері (з автоматичним перезапуском при ребуті сервера):

```bash
# 1. Запуск контейнера у фоні
docker compose up -d --build

# 2. Перегляд логів роботи
docker compose logs -f

# 3. Зупинка (за потреби)
docker compose down
```
